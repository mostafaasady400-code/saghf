# ارزیابی مستقل قیمت ملک سقف

مرجع رابط: https://smart.amlakmim.com/ — مشاهده فرم و /api/meta عمومی.
فرمول مرجع خصوصی است. طبق انتخاب کاربر، این پیاده‌سازی مدل مستقل سقف است؛
نه کپی مدل مرجع و نه یک مدل یادگیری ماشین آموزش‌دیده.

مسیر: /properties/valuation
API با CSRF: POST /properties/api/valuation/preview

ورودی‌ها: محله، متراژ، سن بنا، خواب، تعداد پارکینگ، طبقه، کل طبقات، واحد در
طبقه، نوع سند، آسانسور، بالکن، انباری، بازسازی و امکانات لوکس.

روش: آپارتمان‌های فروش همان محله با متراژ ±۲۵٪، حداکثر ۷ روز آرشیو، فقط
آگهی عمومی با لینک معتبر، رد واسطه، حذف تکرار بر اساس توکن آگهی. دست‌کم ۵
نمونه لازم است. سن، خواب، طبقه، تراکم و امکانات شناخته‌شده در وزن شباهت
استفاده می‌شوند؛ قیمت با میانه وزنی و بازه چارک اول تا سوم محاسبه می‌شود.
بازه، فاصله اطمینان آماری یا قیمت معامله نیست.

برای هر منبع حداکثر ۵۰۰ رکورد تازه بررسی و نزدیک‌ترین ۳۰ نمونه استفاده
می‌شود. Property تاریخ ثبت در سقف دارد، نه تاریخ قطعی انتشار آگهی. داده قدیمی
زنده معرفی نمی‌شود. داده خصوصی دفتر یا شماره مالک وارد خروجی نمی‌شود.

محدودیت: نوع سند، تعداد دقیق پارکینگ، بازسازی و امکانات لوکس در داده فعلی
متادیتای کافی ندارند؛ هیچ ضریب قیمت حدسی برایشان اعمال نشده است. کیفیت ساخت،
نورگیری و موقعیت دقیق نیاز به کارشناسی دارند. ارز و طلا بدون منبع نرخ معتبر
نمایش داده نمی‌شوند. فرم پیامک/OTP مرجع یا داده مشتری به سرویس مرجع ارسال نمی‌شود.

تست: python -m pytest -q tests/test_property_valuation.py
