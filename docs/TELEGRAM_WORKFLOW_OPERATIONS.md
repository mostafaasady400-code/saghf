شش اقدام در سه ردیف دوگزینه‌ای: جست‌وجوی ملک، پیشنهادهای مناسب من، ملک‌های نشان‌شده، شرایط جست‌وجوی من، پیگیری و بازدید، ارتباط با کارشناس. پیشنهادها و نشان‌شده‌ها مستقیم باز می‌شوند. فرم نیمه‌تمام قابل ادامه است؛ جایگزینی پیش‌نویس فقط پس از تأیید درخواست جدید انجام می‌شود. فعال/متوقف‌بودن جست‌وجو گزینه مناسب را تعیین می‌کند. راهنمای بازدید و علت نبود پیشنهاد در پشتیبانی موجود است و دکمه‌های قدیمی همچنان شناخته می‌شوند.

تست‌ها: 151 تست رگرسیون پاس؛ پنج تست جدید مسیرهای منو پاس؛ اجرای نهایی 62 تست مشتری پاس (مجموعه‌ها هم‌پوشانی دارند). compileall موفق؛ تست واقعی runner --check موفق؛ runner جدید در لحظه بررسی PID=4360 و بدون نشانگر خطا بود. نمایش نهایی گوشی هنوز نیازمند تست کاربری است. این ادامه فقط کد و تست بات و این سند بات را تغییر داد؛ وب‌اپ، crawler، منوی دفتر و دیتا پاک یا تغییر داده نشدند. commit/push انجام نشد.

## اجرای مستقل

سه پردازش جدا، بدون وابستگی به اجرای وب‌اپ:

```powershell
python -m telegram_bot.runner
python -m telegram_bot.extraction_jobs
python -m telegram_bot.operations
```

بررسی اتصال بات: `python -m telegram_bot.runner --check`
بررسی سلامت سرویس‌ها: `python -m telegram_bot.operations --check`
توکن فقط از تنظیمات محلی خوانده می‌شود؛ هیچ توکن یا شماره‌ای در این سند نیست.

## مسیر پیاده‌شده

- `/start` همیشه مشتری است؛ `/office` تنها برای عضو معتبر دفتر است. فرمان‌های دفتر در منوی عمومی قرار نمی‌گیرند.
- کیبورد مشتری و دفتر قابل بستن است (`is_persistent=False`). دکمه رسمی Menu روی فرمان‌ها تنظیم می‌شود؛ `/menu` منوی پنل فعلی را باز می‌کند. `/start` فرم نیمه‌تمام را قابل ادامه نگه می‌دارد.
- Back سیستم‌عامل فرمان بات نیست. «برگشت» داخل فرم به مرحله قبل می‌رود؛ «منوی اصلی» یا `/menu` به خانه می‌روند. اصلاح نمایش Android نیازمند آزمون روی گوشی است.
- نیاز مشتری نسخه‌بندی می‌شود؛ توقف جست‌وجو وضعیت فروش پرونده CRM را به «از دست رفته» تبدیل نمی‌کند.
- پیشنهادها دلیل تطابق دارند. علت رد فایل ذخیره می‌شود، بدون تغییر خودکار نیاز مشتری.
- پشتیبانی پیگیری و زمان بازدید پیشنهاد می‌دهد؛ فقط قبول مشتری برای فایل داخلی معتبر، بازدید ایجاد می‌کند. فایل آرشیوی خودکار به فایل داخلی تبدیل نمی‌شود.
- مدیریت نتیجه بازدید و ثبت نظر مشتری، با کنترل مالکیت پرونده و تأیید یک‌بارمصرف انجام می‌شوند.
- یادآورها و پیشنهادهای بازدید از Outbox پایدار ارسال می‌شوند. پاسخ مبهم شبکه «unknown» است و دوباره خودکار ارسال نمی‌شود؛ فقط 429 با سقف تلاش retry می‌شود.
- پایش پنج سرویس و پشتیبان روزانه SQLite با آزمون بازیابی فعال است. شکست backup اعلان‌ها را متوقف نمی‌کند. بررسی سلامت به معنی تأیید نشست دیوار نیست.
