# اتصال بات به موجودی و استخراج موجود سایت

بات مستقل از فرآیند وب اجرا می‌شود و از همان تنظیمات دیتابیس استفاده می‌کند.

مسیر درخواست: تأیید مشتری → صف پایدار extraction_jobs → inventory_bridge →
InstantOnDemandExtractor (همان سرویس routes/properties.py) → دیتابیس مشترک →
recommendations و تطبیق هوشمند مشتری.

بات هیچ CDP، Chrome، Playwright یا کرولر جایگزینی ایجاد نمی‌کند. شکست سرویس
به وضعیت failed می‌رود و موجودی قبلی نتیجهٔ زنده معرفی نمی‌شود. سقف اجرای
درخواست در سرویس موجود ۱۸۰ ثانیه است؛ این سقف تضمین تکمیل پوشش نیست.

فیلتر متراژ، معامله، محله و بودجه (از جمله اجاره صفر) به سرویس موجود منتقل
می‌شود؛ تعداد خواب و امکانات هنگام خواندن نتیجه از دیتابیس کنترل می‌شوند.
فایل عمومی دیوار از فایل خصوصی دفتر جداست؛ فایل خصوصی فقط با مجوز دفتر نمایش داده می‌شود.

اجرا در ریشه پروژه:

    python -m telegram_bot.runner
    python -m telegram_bot.extraction_jobs

این دو فرآیند را هر کدام فقط یک بار اجرا کنید. پیام آزمایشی خودکار ارسال نشد.
