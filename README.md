# 🏛️ سامانه یکپارچه مدیریت و فایلینگ املاک «سقف» (Saghf Real Estate CRM & Intelligence)

یک پلتفرم مدرن و ماژولار مبتنی بر **Python + Flask + SQLite** برای مدیریت کامل چرخه فروش و فایلینگ دفاتر املاک، مجهز به موتور کراولینگ هوشمند از دیوار و شیپور، موتور تطبیق هوشمند دوطرفه ملک و متقاضی، و رابط کاربری اختصاصی **Neon Dark Glassmorphism**.

---

## ✨ ویژگی‌های کلیدی سیستم

### ۱. 🕷️ کراولر پیشرفته دیوار و شیپور (`crawler/`)
* اتصال مستقیم به API رسمی دیوار و وب‌سرویس‌های شیپور برای استخراج فایل‌های رهن، اجاره و فروش مسکونی و اداری.
* استخراج دقیق فیلدهای متراژ، قیمت کل، قیمت هر متر، ودیعه، اجاره ماهانه، سال ساخت، امکانات و تصاویر.
* مانیتورینگ زنده در پس‌زمینه (Multithreaded) همراه با قابلیت جلوگیری از ثبت فایل تکراری (Deduplication).
* دکمه تک‌کلیک «تبدیل به فایل رسمی دفتر» برای پیوست اطلاعات مالک و ثبت در فایلینگ اختصاصی.

### ۲. 🗄️ پایگاه داده رابطه‌ای SQLite (`database/`)
* ساختار استاندارد رابطه‌ای شامل جداول `properties`, `owners`, `clients`, `matching_records`, `interactions`, `visits`, `agents`.
* ارتباط تنگاتنگ پایگاه‌های داده «ملک/مالک» و «مشتری/تقاضا».

### ۳. ⚡ موتور تطبیق هوشمند دوطرفه (AI Smart Matching Engine)
* **ملک ⟷ مشتری**: رتبه‌بندی لحظه‌ای متقاضیان واجد شرایط برای هر ملک بر پایه تطابق بودجه، منطقه، متراژ و امکانات الزامی.
* **مشتری ⟷ املاک**: پیشنهاد بهترین فایل‌های موجود دفتری و آگهی‌های تازه کراول شده به هر خریدار یا مستاجر.
* **کنسول تطبیق متمرکز (`/matching`)**: شناسایی و برجسته‌سازی فرصت‌های معامله با شانس موفقیت بالا (بالای ۸۰٪).

### ۴. 📈 مدیریت چرخه فروش و ابزارهای CRM (`routes/crm.py`)
* **قیف فروش کانبان (`/crm/pipeline`)**: پیگیری مراحل سرنخ (جدید، تماس اولیه، در حال بازدید، مذاکره، عقد قرارداد).
* **تاریخچه تماس‌ها و پیگیری‌ها (`/crm/calls`)**: ثبت لاگ مکالمات و یادآوری تاریخ پیگیری بعدی.
* **تقویم و ارزیابی بازدیدها (`/crm/visits`)**: هماهنگی قرارهای بازدید و ثبت نمره تمایل به معامله (۱ تا ۵).

### ۵. 🎨 طراحی بصری Neon Dark Glassmorphism
* استایل شیشه‌ای (Glassmorphism) با بلور عمیق و حاشیه‌های درخشان.
* لهجه‌های نوری نئون فیروزه‌ای، سبز زمردی، بنفش و کهربایی.
* پشتیبانی کامل از زبان فارسی، راست‌چین (RTL) و تایپوگرافی با فونت محبوب وزیرمتن (Vazirmatn).
* نمودارهای آماری تحلیلی مناطق و مراحل معامله با Chart.js.

## 🚀 راهنمای راه‌اندازی و اجرا

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. مقداردهی اولیه پایگاه داده (اختیاری)
```bash
python seed_data.py
```

### ۳. اجرای سرور توسعه
```bash
python app.py
```
سپس مرورگر خود را باز کرده و به آدرس زیر مراجعه نمایید:
👉 `http://127.0.0.1:5000`

## 📁 ساختار پروژه

```
saghf/
├── app.py                     # نقطه ورود وب‌سرور Flask و پیکربندی فیلترها
├── config.py                  # تنظیمات دیتابیس SQLite و پارامترهای کراولر
├── requirements.txt           # وابستگی‌های پایتون
├── seed_data.py               # اسکریپت بارگذاری داده‌های نمونه اولیه
├── verify_system.py           # تست خودکار روت‌ها و عملکرد کراولر
├── database/
│   ├── db.py                  # نمونه SQLAlchemy
│   └── models.py              # مدل‌های داده (Property, Owner, Client, Visit, ...)
├── crawler/
│   ├── divar_crawler.py       # کراولر دیوار
│   ├── sheypoor_crawler.py    # کراولر شیپور
│   └── crawler_manager.py     # مدیر صف و اجرای پس‌زمینه کراولر
├── services/
│   ├── matching_service.py    # موتور تطبیق دوطرفه ملک و مشتری
│   ├── scoring_service.py     # سیستم ارزش‌گذاری و نمره‌دهی فایل‌ها
│   └── analytics_service.py   # محاسبات آماری و شاخص‌های کلیدی
├── routes/
│   ├── dashboard.py           # روت داشبورد مدیریتی
│   ├── properties.py          # روت‌های مدیریت املاک و فایلینگ
│   ├── clients.py             # روت‌های بانک متقاضیان
│   ├── matching.py            # روت‌های کنسول تطبیق
│   ├── crm.py                 # روت‌های کانبان، تماس‌ها و بازدیدها
│   └── crawler_api.py         # API کنترل و استریم لاگ‌های کراولر
├── static/
│   ├── css/                   # استایل‌های Glassmorphism و Neon Dark
│   └── js/                    # لاجیک مانیتورینگ زنده کراولر و توست‌ها
└── templates/                 # قالب‌های Jinja2 با ساختار RTL
```
